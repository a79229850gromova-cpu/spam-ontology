# Фейковые сообщения и спам
## 1. Сущностные характеристики (ITU-T)
- Электронная форма и низкая стоимость
- Незапрошенный характер
- Массовость и повторяемость
- Использование адресов без согласия
- Скрытый или поддельный источник
- Мультимодальность: текст, аудио, видео
## 2. Среды и каналы доставки
- E-mail (уязвимости SMTP)
- Мобильные сети (SMS / MMS, SS7)
- IP-мультимедиа (SPIM, SPIT / VoIP)
- Веб и соцсети (фишинговые сайты, фейк-приложения)
- Офлайн-триггеры (посылки с QR-кодами)
## 3. Таксономия атак и схем
- Фишинг / Спуфинг
- Компрометация деловой почты (BEC)
- Имперсонация (госорганы, ФБР, техподдержка)
- Инвестиционный и фин. фрод (криптобиржи, пирамиды-игры)
- Схема «Обратный звонок»
- Сигнальные SMS-атаки (SS7)
  - Faking (подмена адреса SMS-C / SCCP / MAP)
  - Spoofing (подмена номера MSISDN)
  - Open SMS-C (отправка в обход HPMN)
  - DoS (ложный статус доставки)
## 4. Технические механизмы
- Генеративный ИИ
- Phishing-as-a-Service (PhaaS)
- Вредоносное ПО и NFC-атаки (NFC Gate)
- SIM Swap
- Ботнеты и зомби-узлы
- Открытые релеи (Open Relay)
## 5. Цели и объекты воздействия
- Кража учётных данных и SMS-кодов
- Хищение средств (карты, счета, СБП, крипта)
- Обманная подписка (Premium Short Codes)
- Заражение вирусами и отказ в обслуживании
- Субъекты: физлица (60+), юрлица, топ-менеджмент, операторы
## 6. Меры выявления и защиты
- Иерархическая модель (ITU-T)
  - Инфраструктура (защита ОС, роли, логи, МЭ)
  - Сервисы (аутентификация, Flow Control, трассировка)
  - Приложения (фильтрация по адресу/контенту, жалобы)
- Защита сигнальных сетей (GSMA)
  - Мониторинг (C7-зонды, сверка MAP/SCCP, TAP-IN)
  - Блокировка (Screening на HLR/MSC, SMS Home Routing)
- Регуляторные меры (Центральный банк)
  - Антифрод по кредитам/банкоматам, база дропперов
  - Блокировка номеров (Минцифры) и маркировка счетов
  - Разделегирование доменов и блокировки Генпрокуратуры
  - Сервис («кнопка») в приложениях банков
